# 书阁 — 独立私密空间与零延迟全链路加密方案

为「书阁」构建基于浏览器原生硬件加速（Web Crypto API `AES-256-GCM`）的**独立私密空间**。所有移入私密空间的书籍、目录大纲及高亮批注均在本地数据库中以高强度密文存储，公开书架与统计面板不留任何痕迹；解锁后通过内存会话密钥与预解密缓存实现 **< 15ms 零延迟秒开**，并配备窗口切出防窥遮罩与闲置自动重锁机制。

  - **窗口防窥保护**：处于「私密空间」或正在阅读私密书籍时，一旦切换浏览器标签页、最小化窗口或窗口失焦，界面立即覆盖高强度毛玻璃防窥护盾并锁定，防止系统任务视图缩略图或旁人窥屏。

## 1. 核心理念与用户体验价值

- **功能概述**：提供一套兼具密码学安全性与极致阅读流畅度的本地私密藏书室。支持将现有书籍一键加密移入私密空间、在私密空间内直接导入私密文档（TXT / Markdown）、以及将私密书籍解密还原至公开书架。
- **适用场景**：阅读私人日记手稿、内部技术文档、商业机密研报、个人财务记录或不便在公共书架展示的私人藏书。
- **核心价值**：
  1. **落盘零明文**：IndexedDB 数据库中仅保存 `AES-256-GCM` 密文块与随机向量（IV），书名、作者、正文、章节目录与批注笔记全部加密脱敏。
  2. **阅读零妥协**：避免传统加密阅读器每次翻页或跳转章节时的解密卡顿，完全保留虚拟分页、Markdown 表格、Mermaid 自动换行图表、批注手账及多格式导出能力。
  3. **离屏即隐**：切出标签页或闲置超时立即触发防窥模糊与内存密钥销毁，安全边界清晰可控。

## 2. 交互体验与视觉设计

### 关键用户流程

1. **首次初始化私密空间**：
   - 用户点击书架顶栏右侧的「私密空间」锁形图标（或使用快捷键 `Ctrl/Cmd + Shift + L`，或在任意书籍操作菜单点击「移入私密」）。
   - 弹出极简克制的「创建私密主密码」面板，设置主密码与可选密码提示，系统通过 `PBKDF2 (SHA-256, 100,000 次迭代)` 生成密钥校验凭证。
2. **书籍加密移入与移出**：
   - **移入私密**：在公开书架的「大图标 / 小图标 / 详细」任一视图下，点击书籍的「设为私密」图标，书籍正文、元数据与关联批注立即完成 `AES-256-GCM` 加密并从公开书架消失。
   - **移出至公开**：在已解锁的私密空间内，可一键将书籍「移出私密空间」，数据恢复明文存储并回到公开书架。
   - **私密直传**：处于私密空间时点击「导入」，新导入的 TXT / Markdown 文件将在内存中直接加密为私密书籍，全程不经过公开书架。
3. **快速解锁与无感阅读**：
   - 点击「私密空间」输入主密码，验证通过后在内存中批量解密私密书单（单册耗时约 2~5ms）。
   - 私密空间同样支持 **大图标、小图标、详细** 三种布局及分类筛选、搜索与排序；点击任意书籍即刻进入阅读器，体验与普通书籍完全一致。
4. **防窥护盾与自动重锁**：
   - 当正在浏览私密空间或阅读私密书籍时：
     - **窗口失焦 / 切换标签页**：立即激活全屏防窥遮罩（隐藏所有正文与标题 DOM），并在切换标签页时自动锁定会话。
     - **闲置超时重锁**：支持设置无操作自动锁定时间（如 5 分钟、15 分钟、30 分钟或切出即锁），超时后自动清除内存密钥并退回锁定界面。
     - **主动一键锁定**：私密空间顶栏与阅读器顶部栏均提供「立即锁定」按钮，点击即刻销毁内存密钥并返回公开书架。

### 视觉风格与极简美学

- **审美定位**：延续「书阁」极简、专业、克制的瑞士网格与现代编辑室风格，拒绝廉价的霓虹黑客风或繁琐的徽章堆砌。
- **色彩与空间区分**：
  - 遵循 60-30-10 色彩法则，沿用当前主题变量（`--bg-page`、`--bg-surface`、`--text-primary`、`--accent-primary`）。
  - 进入「私密空间」时，顶栏展示安静克制的「私密空间 · 已解锁」状态标识与「立即锁定」入口，以细微的边框对比度与锁形符号传达安全感。
- **排版与数字规范**：
  - 统计数字、字数、进度百分比及闲置倒计时均采用等宽数字（`tabular-nums`），确保对齐工整。
  - 元数据采用无边框纯文本与中圆点（`·`）分隔，保持零胶囊标签（Zero-Pill）的干净视觉。

## 3. 核心架构决策与权衡

- **决策 1：采用 Web Crypto API (`PBKDF2` + `AES-256-GCM`) 原生加密引擎**
  - *选择方案*：使用浏览器底层 C++ 实现的 `window.crypto.subtle` 接口，通过 16 字节随机盐值（Salt）与 100,000 次 `PBKDF2-SHA256` 派生 256 位 `AES-GCM` 密钥，每册书籍与每条批注均采用独立的 12 字节随机初始向量（IV）进行认证加密。
  - *原因*：原生硬件指令集（AES-NI）加速比纯 JavaScript 加密库快 20~50 倍，1MB 书籍正文解密仅需数毫秒，且具备防篡改完整性校验（GCM Auth Tag），无需引入臃肿的第三方加密依赖。
- **决策 2：落盘全密文 + 会话内存解密缓存（Session Memory Cache）**
  - *选择方案*：IndexedDB 中私密书籍对象的明文属性（`title`、`author`、`content`、`chapters`）全部置空或替换为脱敏占位符，真实数据序列化后加密存入 `encryptedPayload`；解锁后在内存中维护明文副本供 React 视图渲染。
  - *原因*：兼顾「静态数据绝对安全（即使他人打开浏览器开发者工具查看 IndexedDB 也只能看到密文）」与「动态阅读零延迟（分页器、目录跳转、全文搜索直接读取内存明文，0ms 阻塞）」。
- **决策 3：DOM 级防窥护盾（Privacy Shield）而非单纯 CSS 模糊**
  - *选择方案*：触发防窥锁定或标签页切出时，不仅显示极简防窥解锁层，同时在锁定状态下卸载阅读器内渲染的私密明文节点，直到重新输入主密码才挂载。
  - *原因*：既能阻止操作系统多任务切换视图（Alt+Tab / Mission Control）截获屏幕内容，又能防止在锁定状态下通过页面检查器窥探正文。

### 数据模型扩展

1. **私密保险箱配置凭证（`VaultMeta`）**：
   - `isInitialized`: 是否已设置主密码
   - `salt`: Base64 编码的 16 字节随机盐值
   - `verifierIv`: 校验块初始向量
   - `verifierCipher`: 使用主密码派生密钥加密的固定校验签名（用于快速验证密码正确性）
   - `passwordHint`: 可选密码提示语
   - `autoLockMinutes`: 闲置自动锁定分钟数（默认 `5` 分钟，可选 `1 / 5 / 15 / 30` 分钟）
   - `lockOnTabHidden`: 切换标签页或最小化时是否立即锁定（默认开启）
2. **书籍与批注加密载荷（`Book` & `Annotation` 扩展）**：
   - `isPrivate?: boolean`：标记是否属于独立私密空间
   - `encryptedPayload?: string`：`AES-256-GCM` 加密后的 Base64 密文（包含真实 `title`、`author`、`category`、`content`、`chapters`）
   - `encryptionIv?: string`：12 字节随机 IV（Base64）
   - 批注对象同理支持 `isPrivate`、`encryptedPayload` 与 `encryptionIv`，确保私密书籍的书摘与笔记在数据库中同样密文存储。

### 关键交互状态映射

- **公开态（Locked / Public View）**：
  - 书架列表自动过滤 `book.isPrivate === true` 的条目，公开书架的书籍册数、总字数、分类标签、最近阅读、以及统计视图（`StatsView`）均不暴露任何私密书籍信息。
- **解锁态（Unlocked Private Space）**：
  - 用户在弹窗输入主密码 → `verifyMasterPassword` 派生 `CryptoKey` 并校验通过 → 批量并行解密所有 `isPrivate` 书籍与批注至内存状态 → 视图切换至「私密空间」。
  - 在私密空间内阅读、翻页、添加批注、修改进度时，UI 直接读写内存明文对象（零延迟），后台异步调用 `encryptBookRecord` 将最新状态加密写回 IndexedDB。
- **防窥与重锁触发（Privacy Shield & Lock）**：
  - 监听 `visibilitychange`、`window.blur` 及用户交互事件（`mousemove`、`keydown`、`touchstart`、`scroll`）。
  - 当阅读私密书籍或停留在私密空间时，若窗口失焦则立即叠加防窥毛玻璃层；若切换标签页或达到闲置阈值，立即清空内存中的 `CryptoKey` 与明文缓存，弹出密码解锁框，确保隐私万无一失。
